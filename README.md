# Effective Resistance

[English documentation](README.en.md)

Модуль TERA Toolbox, который показывает сопротивления противника с учётом вашего физического и магического пробивания и фиксированного игнора сопротивления.

Сопротивления, полученные от игры, уже содержат действующие порезки. Модуль не рассчитывает их повторно: он применяет только личные характеристики вашего персонажа. Физические и магические значения пересчитываются независимо.

Работает автоматически, без команд и настроек. Не обращается к датацентру, не отслеживает баффы и не отправляет дополнительные пакеты. Отображение меняется только при получении новых сопротивлений от игры. До получения характеристик персонажа значения остаются исходными.

Для установки поместите папку `effective-resistance` в `Toolbox/mods` и перезапустите подключение к игре. Отключите другие модули, пересчитывающие те же сопротивления, чтобы избежать повторной обработки.
